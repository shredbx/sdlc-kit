## Overview

This repository contains a collection of tools and scripts to help with the software development lifecycle (SDLC).
These tools are described and managed by processos-cli / mcp servers that provide capabilities to the SDLC process.

## Structure

platform/ - platform-specific packages, frameworks, application bootstrappable templates and configured applications to work with specific frameworks

.processos/ - sdlc process definitions, templates, and automation scripts
